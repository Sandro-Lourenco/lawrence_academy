# Workflow: criar tela

1. Confirmar Page Spec, rota, ator, tarefa, dados, ações e permissões. Se a
   spec faltar, criá-la como parte do escopo.
2. Mapear jornada, arquitetura de informação, conteúdo e estados aplicáveis.
3. Para tela pública, registrar a tese visual e validar aderência à direção
   Maison Lawrence antes de escolher componentes, fotografia ou motion.
4. Reutilizar tokens e componentes; justificar componente novo.
5. Definir mobile/tablet/desktop, teclado, foco, semântica, escala de texto e
   reduced motion.
6. Implementar UI → controller/provider → use case → repository; sem
   infraestrutura no widget.
7. Testar estados, interações, navegação, responsividade e acessibilidade.
8. Executar UI, Architecture e QA Reviews; Security Review em fluxos sensíveis.
9. Atualizar Page Spec, navegação e componentes.
